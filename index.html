Conceptos Clave

Vocabulario esencial de la IA agéntica

🧠

LLM

Modelo de Lenguaje Grande. Motor de razonamiento del agente que comprende y genera texto.

🤖

Agente

Sistema autónomo que usa un LLM para razonar, planificar y ejecutar acciones para alcanzar un objetivo.

🔌

MCP

Model Context Protocol. Protocolo estándar para conectar el agente con herramientas y fuentes de datos externas.

📜

Rule (Regla)

Instrucción persistente que moldea el comportamiento del agente en todos sus mensajes.

💬

Prompt

Instrucción o contexto específico que guía al agente hacia un resultado concreto en una tarea.

🛠️

Skill / Herramienta

Grupo de instrucciones, prompts y capacidades específicas que el agente puede utilizar para realizar tareas concretas.

Ejemplo Práctico

Configurar el agente paso a paso

1

⚙️ Crear ficha de agente & activar Backlog Management

En Inditex AI, configura el chatmode Backlog Management: activa las skills de Confluence, JIRA, GitHub y Geppetto, y habilita el modo Agente con las Rules correspondientes.

2

📝 Fichero de instrucciones del agente (Prompt de contexto GitHub)

Crea un fichero prompt-github.md con la información del repositorio: convenciones de ramas, estilo de commits, estructura del proyecto…

3

📋 Fichero de prompt con contexto de JIRA

Crea prompt-jira.md con la definición del proyecto JIRA: tipos de incidencias, criterios de aceptación, convenciones de etiquetado…

4

🚀 Completar Historias de Usuario en JIRA con el agente

Prueba el agente pidiéndole que lea el backlog de JIRA y complete las descripciones de las HUs con criterios de aceptación, estimaciones y notas de implementación automáticamente.
